## v2.2.1 (2026-10-01)

### 修复

- **弹出层贴边跑出屏幕**（[#18](https://github.com/Sutera-Diffusus/dsh-whale-musume/issues/18)）：台词气泡与偏好面板此前都用 `left: 50% + translateX(-50%)` 挂在桌宠中心，没有视口钳制——桌宠拖到屏幕最左/最右时有一半在屏幕外，拖到最顶部时向上弹出同样出屏。现在按桌宠的视口位置写 `align` / `valign` 两枚懒标记，CSS 据此换锚定边：贴左/贴右改为贴边对齐，贴顶改为向下弹出并翻转小三角；小三角通过 `--dsh-whale-anchor` 仍精确指回桌宠中心。标记只在贴边时写入、离开边缘即移除，正常位置的样式完全不受影响。

### 工程

- **README 徽章改为自托管，不再依赖 shields.io**：实测 GitHub 的图片代理（camo）会把「带 URL 编码中文」与「需查 GitHub API」的 shields.io 徽章拖到 504 超时——仓库页 9 个徽章里 5 个变成坏图（单元测试 / 平台 / 桌面端 / 旧版 Web / 下载量）。现在 12 个徽章由 `tools/make-badges.mjs` 生成并随仓库分发，图片由 GitHub 自己提供，不经 camo、不经第三方，任何网络环境都能显示。
- **下载量徽章自动更新**：新增 `.github/workflows/refresh-badges.yml`，每天定时 + 每次发版时重算下载量并提交（内容无变化则不产生提交）。

### 测试

- 单元 **142 → 143 全绿**：新增 `i7`，覆盖桌宠贴左 / 贴右 / 贴顶 / 居中四种位置，并断言 CSS 真的消费了这两枚标记（防止标记变成死代码）。
