## v2.5.3 (2026-11-08)

### 适配

- **安装门禁放宽到整条 0.1.0-rc.6–0.2.x 版本线**：`engines.dsh` 从逐段白名单改为 `>=0.1.0-rc.6 <0.3.0-0`。之前被挡在门外的 `0.2.0-rc.1`、`0.2.1-alpha.1`～`alpha.5`、所有 `0.2.2` alpha，以及未来的 `0.2.3`～`0.2.x` 现在都能安装；`0.3.0` 起（含 alpha）仍拒绝。
- **兼容矩阵补齐**：`dsh.compatibility.dshReleases` 增加 `0.2.0-rc.1` 与 `0.2.1-alpha.1`～`alpha.5`，统一标 `unknown`；已核对过的 `0.2.0-rc.2`、`0.2.1-rc.1`～`rc.5`、`0.2.2-rc.1` 保持 `compatible`。
- **0.1.0-rc.6 之前不放开**：更早的 0.1.0 预发布没有 `dsh.bundle` 安装通道。
